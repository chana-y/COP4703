MECHWAR-X — CONSOLIDATED PROJECT

This package contains SQL/ and GUI/. No standalone repair scripts are needed.
The AI disclosure remains in the source files.

UPDATE YOUR CURRENT PROJECT
1. Close the running GUI.
2. Extract MechWarX_Project.zip. Copy the contents of its SQL and GUI folders
   into the matching folders in C:\Users\Student\Downloads\MechWarX_Project.
   Replace the matching files. Keep all six GUI Python files together.
3. The old repair_missing_tables.sql and repair_stored_procedures.sql files can
   be removed from your project folder; their changes are now in files 02 and 03.
4. In MySQL Workbench, open SQL/02_create_tables.sql. Execute the entire file.
   Existing tables and their data are kept; any missing project tables are added.
5. Open SQL/03_stored_procedures.sql. Execute the entire file INCLUDING the
   DELIMITER lines. Select all code and use the plain lightning-bolt button.
   This reinstalls the project's seven procedures and three triggers.
   Check Action Output for errors. The final queries list 7 procedures/3 triggers.
6. Skip SQL/04_sample_data.sql if you already loaded its demonstration records.
7. Launch from PowerShell:
   cd "C:\Users\Student\Downloads\MechWarX_Project\GUI"
   py main.py
   Enter your MySQL connection details. You should see all four tabs.

FIRST INSTALLATION ON A NEW DATABASE
Run SQL files 01, 02, 03, 04 in that order. Optionally run 05 for tests.
Install the Python dependency from the GUI folder:
   py -m pip install -r requirements.txt
Then run py main.py.

EVERYDAY STARTUP
Only run py main.py. The database retains its tables and stored procedures.
You do not need to execute SQL files every time you open the app.
